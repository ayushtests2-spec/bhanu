# Bhanuuuuu Birthday Wonderland 💗

A static, mobile-friendly birthday website with:
- A welcome/envelope opening screen
- Your 10 personal love notes
- A photo gallery with full-screen lightbox
- Long-distance and future-together sections
- A surprise gift reveal

## Preview locally
Open `index.html` in a browser. Internet is only needed to load the Google Fonts; the site and photos themselves are local.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new **public** repository, for example `bhanuuu-birthday`.
3. Upload the contents of this folder (make sure `index.html` is at the repository root and keep `assets/photos/`).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main**, folder **/(root)**, then Save.
7. Wait a minute or two. GitHub will show your public website URL in the Pages section.

The free public GitHub Pages URL remains available while the repository/account is active and in good standing. A custom domain is optional and usually costs money.

## Personalize
- Edit the captions and wording in `index.html`.
- Replace photos inside `assets/photos/` while keeping the same filenames, or update the filenames in the `memories` array.
- Do not upload private photos if you are uncomfortable with anyone who has the public link viewing them. GitHub Pages sites are public.
